# FITCORE – Smart Gym Membership Management System

Smart Gym Membership Management System using Java Swing and MySQL.

## Features
- Member Management
- Payment Management
- Trainer Management
- Attendance Management
- Membership Plan Management
- Member Search
- Payment History
- Pending Fees Management
- Membership Expiry Tracking

## Technologies
- Java
- Java Swing
- MySQL
- JDBC
- Eclipse IDE
